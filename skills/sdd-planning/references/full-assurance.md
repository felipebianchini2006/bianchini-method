# Perfil Full

Aplicar somente quando o perfil Full foi justificado.

Pode adicionar, conforme a exigência real:

- specs complementares por domínio crítico;
- rastreabilidade requisito → spec → plano → código → teste;
- evidência consolidada de testes;
- mapa design → implementação;
- revisão adversarial de contratos e regras críticas;
- matriz de jornadas e edge cases;
- ADRs para decisões difíceis de reverter.

Mesmo no Full:

- não duplicar texto entre artefatos;
- não revisar partes sem risco apenas para completar uma checklist;
- não registrar saída de teste em mais de um lugar;
- não criar documento vazio ou com seções não aplicáveis;
- manter o Git e o ledger do SDD como histórico operacional primário.
